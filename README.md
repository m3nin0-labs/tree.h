# tree :deciduous_tree:

An another implementation of a numeric binary tree for C/C++

### Building

To build the example:

A) Create a build directory:

```bash
mkdir build
cd build
```

B) Generate build files with CMake:

```bash
cmake ..
```

C) Compile the example:

```bash
make
```

D) Run the example:

```bash
./example
```
